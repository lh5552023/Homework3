Task 1: Conceptual Questions

  1. If the working directory is myfolder/homework/, the relative path to access myfolder/MyData.csv is ../MyData.csv. The .. moves up one directory from the homework folder to the myfolder folder.

  2. What are the major benefits of using R projects: The working directory automatically sets to the project root folder. Relative paths like myfolder/MyData.csv work for everyone who want to access them in the current working directory of their R project. RStudio reopens tabs, history, and cursor locations right where you left off for that specific project. You can move the entire project folder to another computer or share it via GitHub, and code runs without changing file paths.

  3. Git is a version control system that tracks changes made to files and allows users to keep different versions of their work. GitHub is an online platform that hosts Git repositories and makes it easy to store, share, and collaborate on projects.

  4. Two main differences between a tibble and a data.frame are:

    • Tibbles print only the rows and columns that fit on the screen instead of the entire data set.

    • Tibbles are more strict about how they handle variables and do not automatically change things such as variable names or data types in the way traditional data frames might.

getIQR <- function(x, ...) {
  q <- quantile(x, probs = c(0.25, 0.75), ...)
  unname(q[2] - q[1])
}
